# Xpeccy+

A ZX Spectrum emulator for Windows and Linux, with a built-in debugger.

Xpeccy+ is a fork of [Xpeccy](https://github.com/samstyle/Xpeccy) by SAM style. All the
emulation code comes from that project. This fork does not claim authorship of it.

Current version: **2026.0** (development). Forked from upstream build `20260801`.

## Why a fork

Upstream Xpeccy is a multi-platform emulator: ZX Spectrum and clones, plus MSX, Game Boy,
NES, Commodore 64, BK0010, IBM PC and more. It is maintained by one author, who no longer
accepts pull requests, so fixes made here cannot go back upstream.

The two projects also want different things. Upstream adds more machines. Xpeccy+ keeps
the ZX Spectrum as the main target and spends its effort on the parts a user actually
touches every day.

## Direction

- ZX Spectrum first. Other machines inherited from upstream still work, but they are not
  the priority and will be moved out of the way of the ZX user interface.
- Better everyday use: input latency, tape and disk handling, screen output, defaults that
  make sense.
- A debugger that is pleasant to work in.
- Real documentation.

This is not an attempt to compete with Fuse or Unreal Speccy on emulation accuracy.

## What is already in

On top of upstream build `20260801`:

- **TZX loading fixes** - correct handling of several block types, and auto-play for
  loaders that bypass the ROM routine.
- **Memory heat map** - per-cell read/write/exec counters for RAM and ROM, with CSV export
  and a standalone PNG visualizer (`tools/heatmap_png.py`).
- **Lower input lag** - emulation is paced by a wall-clock timer instead of the audio
  callback, plus a "Low latency" video option.

## Build

Requirements: CMake, a C/C++ compiler, Qt (5 or 6), SDL (1.2 or 2), and zlib.

```
mkdir build && cd build
cmake [options] ..
make
```

Options:

| Option | Values | Meaning |
| --- | --- | --- |
| `-DQTVERSION=` | `5` (default) or `6` | Qt version |
| `-DSDL1BUILD=` | `0` (default) or `1` | use SDL 1.2 instead of SDL2 |
| `-DUSEOPENGL=` | `1` (default) or `0` | draw through a QtOpenGL widget |
| `-DUSEQTNETWORK=` | `0` (default) or `1` | QtNetwork support, experimental |
| `-DXRELEASE=` | `0` (default) or `1` | release version string, without `-dev` and build date |

The result is the `xpeccy-plus` executable. On Linux you can also build a package with
`make package`, or install with `make install`.

Windows builds are supported and used daily here (MinGW + Qt), unlike in upstream. A
proper Windows build script is coming; for now configure CMake with your own MinGW, Qt and
zlib paths.

`version.h` is generated by CMake from `cmake/version.h.in` and is not stored in the
sources. Development builds show the build date in the window title.

By default only the ZX Spectrum 48K romset is included, without TR-DOS.
